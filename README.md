Weather Trend Analysis Using Python

Project Overview

This project analyzes historical weather data using Python to understand changes in temperature, humidity, and wind speed.

Objectives

- Analyze monthly and yearly temperature trends.
- Analyze monthly humidity trends.
- Analyze monthly wind speed trends.
- Compare average temperatures across five cities.

Technologies Used

- Python
- Pandas
- NumPy
- Google Colab

Dataset

Historical Hourly Weather Data

Source: "Kaggle Dataset" (https://www.kaggle.com/datasets/selfishgene/historical-hourly-weather-data)

Analysis Performed

1. Data loading and cleaning.
2. Temperature trend analysis.
3. Humidity trend analysis.
4. Wind speed trend analysis.
5. Temperature comparison across five cities.

Conclusion

This project demonstrates the use of Python for data cleaning, analysis of historical weather data.
